# 1Crystals

## 📖 仓库简介

欢迎来到 **1Crystals**。这是一个个人综合项目仓库，主要用于存放和记录我在技术学习、项目实践以及日常折腾中的各种代码和实验。

本仓库包含多个独立的项目模块，涵盖前端页面、后端服务、代码练习场以及 AI Agent 相关的探索。

## 📂 模块说明

以下是仓库中各个文件夹的简要说明：

*   **AnythingLLMWebPage**：与 AnythingLLM 相关的网页端实践项目。
*   **PetHospitalServer**：宠物医院服务端项目（后端服务与接口开发）。
*   **Playground**：个人代码实验场，用于测试新技术或存放零散代码片段。
*   **agent/Practice01**：AI Agent 相关的基础练习与探索。

*(注：各子项目具体的技术栈和运行方式，请进入对应目录查看。)*

## 🚀 如何使用

由于各个模块相互独立，如果你想运行或查看某个具体的项目，请进入对应的文件夹，查看其中的代码或专属说明。

```bash
git clone https://github.com/[你的GitHub用户名]/1Crystals.git
cd 1Crystals/[想要查看的子文件夹名称]
